# Launch Plan Generator
A launch plan generator that takes an idea and generates a 7-day launch plan.

## Features
* Generates a launch plan with MVP feature list, target launch date, marketing channels, and pricing strategy
* Auto-populates with data from the selected idea
* Plan is downloadable as PDF and shareable link

## Usage
1. Create an idea with name, description, features, marketing channels, and pricing strategy
2. Generate a launch plan using the `generate_launch_plan` function
3. Convert the launch plan to JSON using the `launch_plan_to_json` function
4. Generate a PDF using the `launch_plan_to_pdf` function
5. Share the launch plan using the `share_launch_plan` function
