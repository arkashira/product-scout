# breakeven.md

## Unit Economics & Break-even Analysis

### Cost per Active User
- **Compute**: $0.10/user/month
- **Storage**: $0.05/user/month
- **Bandwidth**: $0.03/user/month
- **Total Cost per Active User**: 
  - **Total** = Compute + Storage + Bandwidth
  - **Total** = $0.10 + $0.05 + $0.03 = **$0.18/user/month**

### Pricing Tiers
| Tier Name        | Price ($/mo) | Features                                                                 |
|------------------|--------------|--------------------------------------------------------------------------|
| **Basic**        | $9           | Access to product discovery tool, 5 product ideas/month, community support |
| **Pro**          | $29          | Access to product discovery tool, 20 product ideas/month, community support, analytics dashboard |
| **Premium**      | $49          | Access to product discovery tool, unlimited product ideas, community support, advanced analytics, priority support |

### Customer Acquisition Cost (CAC) Range
- Estimated CAC: **$50 - $100** per user (including marketing, sales, and onboarding costs)

### Lifetime Value (LTV) Estimate
- Average Monthly Revenue per User (ARPU):
  - Basic: $9
  - Pro: $29
  - Premium: $49
- Assuming an average user lifespan of 24 months:
  - LTV (Basic) = $9 * 24 = **$216**
  - LTV (Pro) = $29 * 24 = **$696**
  - LTV (Premium) = $49 * 24 = **$1,176**
- Average LTV (assuming equal distribution across tiers): 
  - LTV = (216 + 696 + 1176) / 3 = **$696**

### Break-even Users Count
- Fixed Costs (assumed): $2,000/month (marketing, salaries, operational costs)
- Contribution Margin per User:
  - Basic: $9 - $0.18 = **$8.82**
  - Pro: $29 - $0.18 = **$28.82**
  - Premium: $49 - $0.18 = **$48.82**
- Break-even Users Count:
  - Basic: $2,000 / $8.82 ≈ **227 users**
  - Pro: $2,000 / $28.82 ≈ **69 users**
  - Premium: $2,000 / $48.82 ≈ **41 users**

### Path to $10K MRR
- Target MRR: **$10,000**
- Pricing Strategy:
  - **Tier Distribution**: Assume a mix of 40% Basic, 40% Pro, and 20% Premium
- Users Needed:
  - Basic: 40% of $10,000 = $4,000 → $4,000 / $9 ≈ **445 users**
  - Pro: 40% of $10,000 = $4,000 → $4,000 / $29 ≈ **138 users**
  - Premium: 20% of $10,000 = $2,000 → $2,000 / $49 ≈ **41 users**
- Total Users Needed: **445 + 138 + 41 = 624 users**

### Summary
To achieve $10K MRR, we need approximately **624 active users** distributed across the three pricing tiers, with a balanced focus on acquiring users from each tier to maximize revenue while maintaining a sustainable CAC.
